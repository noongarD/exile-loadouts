Your first character

Start with a campaign route and change one thing at a time.

  1. Pick a skill

    Choose something you enjoy casting or attacking with. Use one main skill for damage and link support gems to it.

  2. Follow the campaign

    Open the first campaign loadout for skills and gear. In the editor, open the gem rewards to see which quests and vendors to visit.

  3. Make a copy

    Try a different support gem or passive path in the editor. Export it to the free Path of Building app to check the change.

Paste a PoB build code or choose a PoB XML file. For a pobb.in link, open the page and copy its build code.

Export build

Paste the generated code into Path of Building’s Import/Export Build tab. Select Loadouts there to switch stages.
